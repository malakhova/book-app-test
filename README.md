# Тестовое задание Book App

## Описание проекта

**Технологии**: PHP 8.4, MySQL 8.0, Docker

**Основные возможности:**
- CRUD операции для книг и авторов
- Подписка гостей на новых книги авторов
- SMS уведомления о новых книгах
- Отчет "ТОП-10 авторов по количеству книг за год"

**Реализация без верстки**

## Структура проекта:

Выбран шаблон Yii2 advanced для реализации CMS и сайта (подписка, отчеты) в одном проекте.
По хорошему - это должно быть 2 раздельных web-приложения

```
book-app/
├── backend/           # CMS (Content Management System)
│   ├── controllers/   # CRUD книг и авторов
│   └── services/      # Бизнес-логика CRUD сущностей
├── frontend/          # SITE 
│   ├── controllers/   # Подписки(site/subscribe),
│   │                  # Отчет(report/top-ten-authors)
│   └── services/      # Бизнес-логика (отчеты, подписка) 
└── common/            # Общая логика
    ├── models/        # Mодели
    ├── repositories/  # Репозитории для доступа к данным
    └── services/      # Бизнес-логика (SMS, нотификации)

```

## Технические решения
- **Работа с БД**
  - **ActiveRecord** для CRUD (валидация, создание, удаление)
  - **Query Builder** для составных запросов

- **SMS уведомления**
  - **Сервисный слой** в common - доступен из backend и frontend
  - **Интерфейс SmsSender** - легко заменить провайдера

- **Общие архитектурные решения**
  - **Service Layer** - отделение бизнес-логики от контроллеров
  - **Repository Pattern** - тестируемость, замена источника данных
